## Design principles

The theme uses native system fonts, restrained surfaces, compact navigation, Apple-blue links, a narrow reading measure, and a lightweight “On This Page” column. It preserves Pagefind search, generated sidebars, Expressive Code, keyboard navigation, and Starlight's mobile menu.
