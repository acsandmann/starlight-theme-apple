import { Card, CardGrid, LinkCard } from "@astrojs/starlight/components";

```js title="astro.config.mjs" ins={2,6}
import starlight from "@astrojs/starlight";
import starlightThemeApple from "starlight-theme-apple";

export default {
  integrations: [
    starlight({ title: "My Docs", plugins: [starlightThemeApple()] }),
  ],
};
```

## Built on Starlight, refined for reading

Navigation, search, internationalization, and accessibility come from Starlight. The theme adds the typography, hierarchy, and restraint of Apple’s documentation.

<CardGrid>
  <Card title="Apple typography" icon="document">
    System fonts on a 17-point body, bold page titles, and section headings set on Apple’s documentation scale.
  </Card>
  <Card title="A quiet navigator" icon="list-format">
    Neutral sidebar selection, gray group headings, a hairline “On this page” rail, and breadcrumbs that link to section overviews.
  </Card>
  <Card title="Reference pages" icon="open-book">
    Declarations, parameters, metadata, and topic lists for API, configuration, and command references.
  </Card>
  <Card title="Light and dark" icon="moon">
    Both appearances follow Apple’s palettes, and the native appearance control keeps the system setting.
  </Card>
</CardGrid>
