Add the theme to an existing [Starlight](https://starlight.astro.build/getting-started/) site. It needs no configuration and no custom CSS.

## Install the theme

<Steps>

1. Add the package to your project.

   <Tabs syncKey="pkg">
   <TabItem label="npm">

   ```sh
   npm install starlight-theme-apple
   ```

   </TabItem>
   <TabItem label="pnpm">

   ```sh
   pnpm add starlight-theme-apple
   ```

   </TabItem>
   <TabItem label="bun">

   ```sh
   bun add starlight-theme-apple
   ```

   </TabItem>
   <TabItem label="Yarn">

   ```sh
   yarn add starlight-theme-apple
   ```

   </TabItem>
   </Tabs>

2. Add the plugin to your Starlight configuration.

   ```js title="astro.config.mjs" ins={3,8}
   import starlight from "@astrojs/starlight";
   import { defineConfig } from "astro/config";
   import starlightThemeApple from "starlight-theme-apple";

   export default defineConfig({
     integrations: [
       starlight({
         plugins: [starlightThemeApple()],
         title: "My Docs",
       }),
     ],
   });
   ```

3. [Start the development server](https://starlight.astro.build/getting-started/#start-the-development-server).

</Steps>

The theme requires Starlight 0.41 or later and Astro 7.

## What you get

- Apple’s documentation typography, palette, and spacing in light and dark appearances.
- A compact navigation bar with Starlight search, social links, and the appearance control.
- Breadcrumbs above each title, a quiet sidebar, and a hairline “On this page” rail.
- Restyled Starlight components: asides, cards, link cards, tabs, steps, badges, file trees, and code.
- Code blocks in Xcode’s syntax colors through Expressive Code.
- [Reference components](/starlight-theme-apple/reference/components/) for API, configuration, and command references.

Everything else is ordinary Starlight. Write pages in Markdown or MDX, configure the sidebar as usual, and use Starlight components.

## Add header links

Optional settings add primary navigation to the header and a site row to the footer:

```js title="astro.config.mjs"
starlightThemeApple({
  nav: [
    { label: "Guides", link: "/guides/" },
    { label: "Reference", link: "/reference/" },
  ],
  action: { label: "Download", link: "https://example.com/download" },
  footer: {
    links: [{ label: "GitHub", link: "https://github.com/example/project" }],
    copyright: "© 2026 Example",
  },
});
```

Links starting with `/` are resolved against your site’s `base`, so the same configuration works on GitHub Pages project sites. On small screens, header links move to the top of the navigation menu.

See [Configuration](/starlight-theme-apple/configuration/) for every option.
